# Rajeshwari Mali - Portfolio Website

A sleek, modern, fully responsive portfolio website built with vanilla HTML5, CSS3, and JavaScript. Features smooth animations, GSAP-powered interactions, reactive canvas mesh hero, and comprehensive accessibility support.

## 🚀 Live Demo

[View Live Portfolio](https://rajeshwari13d.github.io/portfolio)

## 🌟 Features

- **Fully Responsive Design** - Mobile-first approach, tested across all device sizes
- **Smooth Scroll Navigation** - Active section highlighting with smooth scrolling
- **Interactive Animations** - GSAP ScrollTrigger reveals, 3D card tilt, custom cursor
- **Reactive Canvas Mesh** - Dynamic gradient mesh hero background
- **Performance Optimized** - Lazy loading, preloading, and minimal dependencies
- **Accessible** - WCAG 2.1 compliant, keyboard navigation, screen reader support

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3 (Custom Properties), Vanilla JavaScript (ES6+)
- **Animations**: GSAP 3.12.5 + ScrollTrigger
- **Fonts**: Inter + Space Grotesk (Google Fonts)
- **Build**: No build step required - pure vanilla stack
- **Deployment**: GitHub Pages
