02
Academic / Research Prototype Healthcare AI / Computer Vision / Deep Learning

OphthalmoAI

Using AI to analyse retinal images and explore diabetic retinopathy progression prediction.

Problem

Diabetic retinopathy can progress over time, making early identification and monitoring important. This project explores predicting disease progression from retinal scans instead of focusing only on basic classification.

Approach

  • Retinal image preprocessing and deep learning-based analysis
  • Diabetic retinopathy classification and progression-oriented analysis
  • Explainable AI techniques (Grad-CAM, LIME, SHAP) for model interpretability
  • ResNet50 and VGG16 architecture exploration with Kaggle datasets

Tech Stack

Python PyTorch TensorFlow OpenCV Pillow Matplotlib ResNet50 VGG16 Grad-CAM
