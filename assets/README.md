# Assets Directory

This directory contains all the images, documents, and media files for the portfolio website of Rajeshwari Mali.

## Current Assets

- `favicon.ico` - Website favicon (32x32px)
- `apple-touch-icon.png` - iOS home screen icon (180x180px)
- `profile picture.jpeg` - Profile photo
- `social-preview.png` - Social media preview image
- `social-preview.html` - Alternative social preview generator
- `google-play-badge.png` - Google Play Store badge

## Image Guidelines

### Recommended Formats

- **Photos**: JPEG (.jpg / .jpeg) for photographs
- **Graphics**: PNG (.png) for graphics with transparency
- **Icons**: SVG (.svg) for scalable icons

### Accessibility

- Provide descriptive alt text for all images
- Ensure sufficient color contrast in graphics
- Consider how images appear to screen reader users
